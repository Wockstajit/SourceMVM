# SOURCE:MVM public website

This is the public website and download repository for SOURCE:MVM:
https://wockstajit.github.io/SourceMVM/

This repository only contains the website. Unfortunately, I don't feel comfortable making
SOURCE:MVM open source due to how many things I've reverse-engineered could be used for cheats
and other things. Instead of letting that work go out publicly and letting my use of AI amplify
those other uses of AI, I would rather keep the rebuild private.

Application source is maintained privately. Complete installers are shared through GitHub Releases.

The Download button automatically finds the newest published complete setup exe. It stays
unavailable if no published installer exists. GitHub Pages serves main from the repository root.

Each release includes SHA-256 checksums. The VirusTotal report links to the owner's scan of
SourceMovieMaker.exe, the normal executable installed by the setup. Its exact hash is recorded
in release-verification.json. The website binds the report to the matching setup version.

Update releases use versioned tags, a complete setup exe, its blockmap, and the latest.yml
generated by electron-builder. Upload everything to a draft before publishing it.
