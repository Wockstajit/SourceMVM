// Testers wanted

I need beta testers.

SOURCE:MVM is still early, and it breaks in ways I can’t find on my own. Install it, load a demo and push every tool as hard as you can. When something goes wrong, tell me.

  1. 01

    Try everything

    Fly the camera, build camera paths, swap skins, stack effects and render a clip. If something feels off, report it.

  2. 02

    Environment is super laggy

    Everything under CONFIG → ENVIRONMENT (lighting, weather, fog, sky) is really heavy right now, so expect big frame drops while it’s on. I already know about the lag, but crashes and visual bugs there are still worth reporting.

  3. 03

    Report bugs in-game

    Click in the bottom right of CS2’s main menu or pause menu and tell me what you were doing right before it broke. Your logs get sent along with it, and crashes send a report on their own.

    If it can’t send, it saves the report as a file instead. DM that file to huslerz on Discord.
